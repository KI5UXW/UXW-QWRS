# UXW-QWRS
Pair of bash scripts that install/uninstall WSJT-X, the required RTL-SDR drivers, and SDR++.

The code used to install the RTL-SDR drivers is derived/copied from the official installation instructions as of Jan. 15th, 2026. The link can be found here: https://www.rtl-sdr.com/rtl-sdr-quick-start-guide/

The SDR++ version installed is https://github.com/AlexandreRouma/SDRPlusPlus/releases/download/nightly/sdrpp_ubuntu_noble_amd64.deb. If you need to change this, just edit UXWQWRS.sh with a text editor and replace the link with the one best suited for your distribution.

Made using Ubuntu 24.04.3 LTS on Windows 10 x86_64 & 6.6.87.2-microsoft-standard-WSL2.
